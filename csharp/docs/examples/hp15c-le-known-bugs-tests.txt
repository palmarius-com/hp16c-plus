# HP-15C: the known bugs of the HP-15C Limited Edition, as tests on the original 15C ROM.
# calculator: 15c
#
# Source: "HP-15C LE (Limted Edition) Bug Reports", HP Articles Forum, posted by Katie Wasserman on
# 16 Sept 2011, edited 26 Dec 2011 (https://www.hpmuseum.org/cgi-bin/articles.cgi?read=1089),
# firmware dated 2011-04-15. The list compares the LE with the 15C Classic and the 12C+.
#
# What these tests are: the LE bugs are in the LE's own firmware (a re-implementation), which this
# simulator does not run. It runs the original 15C ROM, which is the reference the bug list compares
# against. So each line states what the Classic does; a calculator with the LE bug would fail it.
# They show that the described sequence works on the Classic ROM, not that the LE bug can be
# reproduced here. The expected values come from the bug report and from arithmetic, not from the
# simulator.
#
# Not testable here (hardware, not keys and display):
#   4) current draw over 20 mA with a key held
#   5) low battery indicator, memory lost without a graceful shutdown
# Not testable on this ROM:
#   6) the ON+g+ENTER self test menu of the LE / 12C+ (the Classic has a different self test)
#
# Start the HP-15C, then Run. Tests build on the line before them.

reset
[FIX] 4
